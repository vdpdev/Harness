# Security Policy

## Supported Versions

This project is under active development. Security fixes are applied to the latest `main`
branch.

## Reporting a Vulnerability

If you discover a security vulnerability, **do not open a public issue.** Please report it
privately so we can triage and ship a fix before public disclosure.

- **GitHub Private Vulnerability Reporting:** use the "Report a vulnerability" button under the
  **Security** tab of the repository (preferred).

Please include:

- A description of the vulnerability and its impact.
- Steps to reproduce.
- Affected version(s) and environment (Node.js version, OS).
- If known, a suggested remediation.

## Disclosure timeline

We aim to acknowledge a report within **72 hours**, provide a remediation plan within
**7 days** for confirmed high-severity issues, and coordinate public disclosure after a fix is
released.
